# tetris
A project for Hack Club terra. It's a tetris clone, made in gdscript.
It can be found at https://felxybozinni.github.io/tetris/WEB%20EXPORT%20FINAL/Tetris.html

It plays like regular tetris:

Left/Right will move the piece from left to right

Down will move it down further

Up will move it straight to the bottom of its path

But I've added some extras- Two bars that when filled will give you their respective benefits. These are an eight cell long bar, and removing the bottom 3 layers from the board.

Win by getting 100000 score! It's not easy!

You lose when the tower of blocks reaches the top- pretty simple. Some of the detection and things is a bit finnicky right now, but I've already spent a long time on it (And its late on a sunday) so i might fix it later. Who knows?
